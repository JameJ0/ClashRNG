# My Personal Project

## Rougelike video game (I'll have to think of a title)

For the term project, I would like to make a rougelike video game.

What is a *rougelike* game?

- RPG (role-playing game)
- Dungeon crawling: the levels will be differnt rooms that can be cleared
- Procedurally generated content (items, enemies, and rewards can be different every level)
- Played on the 2D grid
- Playthrough ends when the player's health drops to 0
- Player losing all their items upon death, meaning the only "progress" is the player's knowledge and skill

The application will display a heads-up display (HUD) of the player's stats (like health and defense), as well as the current level that player is in. There will also be a background, the player model itself, enemie entities, and sometimes background obstacles on the play field. This application is intended for people who enjoy a challenge, and prefer PvE (player versus environment) games over online multiplayer games. Don't worry if the game sounds difficult, you will be able to select the difficulty level in the lobby screen.

This project is of interest to be becasue I've always played video games my whole life, but have never thought to create one myself. I've attempted to create a game in highschool, but the code was a mess becasue of a lack of coding experience. I hope that through this project, I'll have another shot at making a well organized netword of code and classes that is (mostly) bug free, easy to modify for the developer, and can be easily read by someone else.
